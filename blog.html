My Experience Learning Web Development

Learning web development has been an interesting experience. Before starting this module, I knew that websites were made using different technologies, but I did not understand how HTML and CSS worked together.

HTML is used to create the structure of a webpage. For example, headings, paragraphs, links, images and forms can be created using HTML elements. CSS is then used to control the appearance of those elements.

One of the most interesting parts of web development is responsive design. A website should work on different devices, including computers, tablets and mobile phones. CSS media queries can be used to change the layout for smaller screens.

What I Have Learned

  • How to create webpages using HTML.
  • How to style webpages using CSS.
  • How to create responsive layouts.
  • How to use GitHub for version control.

I still have more to learn, especially JavaScript and advanced responsive design. However, building this portfolio has helped me understand the basic process of creating a website.
